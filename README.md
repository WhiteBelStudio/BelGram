# BelGram

BelGram — современный мессенджер с личными чатами, группами, сообществами, каналами, файлами, голосом и видео.

## Статус

**Версия:** 0.1.0 Foundation

Проект находится на этапе создания архитектуры и первого рабочего ядра.

## Архитектура

- `apps/web` — веб-клиент
- `apps/api` — FastAPI backend
- `infra` — Docker и инфраструктура
- `docs` — документация
- PostgreSQL — основная база данных
- WebSocket — realtime-события
- Redis — кеш, presence и фоновые задачи

## Разработка

Требуется Node.js 22+, Python 3.12+ и Docker.

Секреты хранятся только в `.env` и не коммитятся.
